# 方案 A：单城区自由沙盒（当前执行范围）

## 目标

在一个完整街区里提供可玩的自由沙盒，不包含任务链、剧情或 Boss：

- 稳定的地面移动、冲刺、跳跃、飞行；
- 原版角色与已恢复的 49 段动画；
- 市民、车辆、可破坏道具；
- 玩家可以攻击市民，产生受击/死亡/重生；
- 基础战斗与破坏；
- 原版小地图/HUD 的沙盒版本。

## 明确不在范围内

- 任务链、任务 UI、奖励、进度；
- 剧情、过场、对话；
- Boss 战；
- 完整全城所有 district；
- 存档/读档；
- 任务状态机和 active/completed 图标过滤。

以后要加，也必须先完成本方案 A 的验收。

## 验收标准

### A1 移动与相机

- 默认 `?view=play` 稳定出生在地面；
- W/A/S/D、Shift、Space、E/Q、鼠标视角可用；
- 走路/跑步/跳跃/飞行切换无明显穿模或卡死。

### A2 一个完整街区

- 玩家活动范围内地面、楼层、道路、建筑碰撞稳定；
- 至少 1 个明确街区边界，不出现无限下坠或出生在墙里；
- 市民/车辆/道具分布在该街区内。

### A3 市民攻击

- 普通 J 近战、K 远程、E 热视线均能命中市民；
- 市民被命中后进入死亡/倒地，短暂消失，8 秒后重生；
- 市民受击会逃跑/alert；
- baseline 模式下车弱攻击无效、强攻击有效；道具不破坏。

### A4 基础战斗

- 攻击时间轴、命中、伤害、音效、HUD 提示可用；
- 飞行/空中攻击仍可用；
- 无玩家伤害、无失败/惩罚流程。

### A5 HUD

- 小地图显示玩家位置/朝向；
- 不显示任务目标/任务图标（因为本范围无任务）；
- 调试帮助可通过 `?hud=help` 打开。

## 下一步顺序

1. 市民攻击的实机路径：近战/远程/热视线逐一验证，补受击反馈。
2. 定义并验收“一个完整街区”的边界、地面和碰撞，不再无限扩张。
3. HUD 沙盒化：隐藏任务图标/任务进度，只保留小地图/玩家/基础提示。
4. 市民/车辆基础行为：不要求原版 AI，但要有稳定路线/避让/重生。
5. 视觉只做该街区的必要修正，不再开全城材质/天空工程。
6. 通过 A1–A6 后，再讨论是否扩展任务或 Homelander。

## 非目标提醒

方案 A 仍是“接近原版表现的单街区沙盒”，不是完整游戏移植，也不是逐帧/像素等价。所有预览 AI、路线、重生节奏和 HUD 过滤都必须继续标注为 preview，直到有原版证据。
