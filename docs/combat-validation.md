# 街区战斗与自由破坏验证

2026-10-24，本机 Babylon WebGL / IAB；开发入口5178及正式构建预览4178。没有执行原版Windows游戏，以下是Web实现测试，不能替代原游戏运行时对照。

## 自动检查

- npm test：8组碰撞测试、移动/飞行集成（新增E不得上升）、14段攻击时间轴、1.1与0.75倍率、一次命中通知、目标规则与射线遮挡均通过。
- npm run verify:game：26项资产、42场景对象、14人口实例、11路线通过引用、buffer、索引、蒙皮/动画数据和变换检查。
- npm run build：类型检查与Vite构建通过。

## 浏览器操作

- 最终构建能加载住宅街区、原角色、8市民、3车和3报刊箱；车辆轴向经过修正，沿道路往返。原市民步行动作正常。
- 左键显示“近战连击”，右键显示“远程攻击”，与键盘J/K入口一致；Shift+K显示“强力拳波”。
- 按住E期间DOM状态heat=true且截图显示双眼红光束；松开后heat=false，玩家没有上升。一次对准右车道的5秒操作记录9次有效热视线命中，车辆消失，剩余目标14→13，破坏计数0→1。
- 强力攻击造成多个目标击倒/破坏；同一目标没有重复累计。基础交互模式普通攻击后目标数仍14；地面强力攻击后12，计数2。模式切换恢复全部目标、清除计数。
- Esc暂停后按E仍heat=false、paused=true；恢复不残留按键。重置街区恢复角色起点和目标，清空攻击/光束/粒子。
- 最终正式构建加载、左/右键测试期间控制台无新增error/warn。较早开发日志中的材质URI、receiveShadows实例警告已修正，不作为最终构建问题。
- 实机不同视角约30–80+FPS，不能据此承诺其他设备性能。人口与特效加入后的性能仍需在更大城区测量。
