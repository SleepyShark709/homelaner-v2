# Project scope

## Current phase (2026-10-25): original-game restoration only

Restoring UNDEFEATED is the only active primary milestone. The Homelander skin, free-destruction mode, heat vision and other Web-side extensions are frozen optional experiments; they must not be treated as completion evidence or expanded until the restoration gates pass:

1. Capture the real gameplay player/camera transform from the original executable (not the menu Pawn).
2. Re-render the same location/camera and record an honest same-camera comparison.
3. Close the lighting/material/sky/scene-content gaps and restore the missing props.
4. Verify the original animation/state logic, then preserve it on any replacement character.

Status (2026-10-25): gate 1 complete via `WBP_TitleSinboard_C:GameStartEvent()` + one `InputDone()`; the settled gameplay transform is `pawn (-311.999, 7473.891, 167.150)` / `cam (-361.999, 7073.891, 327.150)`, rot `(-10, 90, 0)`. Gate 2 has a first same-camera comparison at `(-3.12, 74.73891)` with camera `(-3.62, 3.2715, 70.73891)`, measured FOV 90 (`PlayerCameraManager:GetFOVAngle()`); the default play camera now uses 90 too. Gate 3 is in progress: the storefront `-Window_mat` and `Tilable_metal_TintC_Inst` now use their recovered colour/tint parameters instead of the neutral fallback; the original 1024×1024 `T_StaticMinimap_Tex`, `map250` ink frame and `T_PlayerIcon` are wired as the default HUD with the recovered `WorldOrigin/BoxExtent` mapping (`?hud=help` restores the authored panel), but the state-driven green/red tint, icon layout and scaling material are not complete. Lighting, contact shadows, remaining HUD elements and materials are still open. `?ssao=1` is an inspection-only screen-space contact-shadow preview, not an original AO/lightmap reconstruction. A `LightingTest` postprocess probe recorded AutoExposure 1..8 and Bloom 2.5, but those values are not MainLevel baked lighting and a Bloom preview was rejected for adding non-original edge glow. Gate 4 remains open.

Until those gates pass, do not call this a faithful port or a successful migration. The current default `?view=play` is the original character/slice; `?skin=homelander`, `?mode=free` and `?retarget=1` are experimental and may be incomplete.

This is a new independent project at E:/undefeated-web. Do not base implementation on the existing homelander-simulator source tree. The original game installation is read-only.
