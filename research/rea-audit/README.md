# 原版还原纠偏审计

用户于2026-10-24明确要求全面REA逆向，认为当前Web演示没有体现原游戏资产。现暂停新玩法扩展，保留演示，不将它计作完整移植。

2026-10-25 进展：当前默认查看器已接入 41 图中已识别的 11,359 个网格组件、46 处参考姿态挂点、144 块原高度场，消除已发现的骨骼材质槽歧义。新增 20 份原 shader 计算合同和 17 关卡启动城市基线。原程序已实际观察到启动菜单和城市广场，尚未通过同机位/同操作验收。见 [当前世界恢复记录](../../docs/world-recovery.md)、[流送控制流证据](../streaming-contract.md) 与 [原程序运行观察](../runtime-observation/report.zh-CN.txt)。下文旧演示数据保留作纠偏依据，不能用它替代当前覆盖，也不能把组件覆盖当作完整游戏完成率。

## 已查明的偏差

| 项目 | 原版可核查内容 | 旧Web演示 |
|---|---|---|
| 世界 | MainLevel直接引用33子关卡；传递闭包共35地图 | 仅MainLevel/ResidentialArea1部分区域 |
| 明确网格引用组件 | 5,463 | 对应252；该比值约4.61%，不是游戏完成率 |

| 玩法 | 原状态机、动画图、AI、关卡加载和任务链 | 主要是人工近似控制器、巡逻与程序特效，只复用了部分原参数/动作 |

以上结论意味着前一版本未达到用户要求；不以“用了原模型”来代替还原验收。以上表格保留纠偏时的基线。后续执行已把全地图显式/模板网格、材质覆写、原高度场和地表混合接入默认 Web 查看器；当前范围、证据与剩余缺口见 [世界恢复记录](../../docs/world-recovery.md)。旧原型移至 `?view=prototype`，原玩法等价恢复仍未完成。

## 原版还原验收要求

每个子系统分开记录六项状态：原包身份已确认、依赖/字节码已解析、控制逻辑已解释、原资源已转换、Web已实现、原游戏运行对照通过。任何一项未完成都要列出缺口。

先恢复完整活动关卡、材质/光照/地形、原角色动作状态与原玩法链，再做同机位画面和输入序列对照。热视线快捷键、自由破坏和祖国人外观全部后置。现有Web测试仅证明旧实现内部可运行，不能证明等价于原游戏。

本目录分开记录：

1. REA 原生分析：实际工具输出、目标SHA-256、引擎版本、地址、调用与反编译证据。此前REA仅有就绪诊断和PE资源检查；没有完整原生反编译。
2. UE 专用解析：UAssetAPI解析关卡/蓝图/材质，UModel导出网格/动画。它们有用，但不冒称REA Evidence。
3. Web实现覆盖：源资源→导出文件→加载对象→渲染/行为的对应，以及所有人工近似和缺失。

恢复顺序：完整主关卡及加载规则→原场景网格/实例/地形→材质与纹理通道/覆写→角色动画状态与原玩法→原版运行对照→Web等价实现。每一步列清楚实际覆盖及未解决项；不是导出所有文件便宣布逆向完成。原版还原通过后才恢复热视线快捷键、自由破坏与外观替换。

不能承诺从Shipping二进制恢复原开发工程、原C++源码、全部编辑器图表或像素完全一致；“全面”指调查范围及证据覆盖，而非伪造无法恢复的部分。
